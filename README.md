# ✨ Raphael Garcia Codes

Um cantinho divertido na web para aprender, consultar e brincar com conteúdo de desenvolvimento.  
Este projeto reúne páginas HTML estáticas com foco em produtividade, estudo e referência rápida.

## 🎯 O que tem por aqui

- Navegação rápida entre páginas úteis
- Ferramentas e dicas para desenvolvedores
- Material para estudar Git de forma prática
- Um espaço com comandos e referências para consulta
- Favicon personalizado para deixar tudo com cara mais profissional

## 🗂️ Páginas do projeto

### 🧰 `dev-tool-kit.html`
Um painel de ferramentas para desenvolvedores, com visual moderno e várias utilidades em um só lugar.  
Ideal para quem quer consultar, testar e organizar tarefas técnicas sem sair da página.

### 🌿 `git-learning.html`
Uma página pensada para aprender Git praticando.  
Ela organiza desafios, comandos e um fluxo visual para ajudar no entendimento dos conceitos.

### ⚡ `helper-commands.html`
Um guia de referência rápida com comandos e dicas úteis.  
Perfeito para bater o olho, lembrar de algo importante e seguir em frente sem perder tempo.

### 👔 `index.html`
A página de currículo/portfólio do projeto.  
Ela apresenta o perfil do autor de forma mais tradicional e serve como porta de entrada do site.

## 🚀 Como usar

1. Abra qualquer arquivo `.html` no navegador.
2. Navegue pelas páginas e explore o conteúdo.
3. Se estiver publicando no GitHub Pages, basta manter os arquivos no repositório principal.

## 🧪 Teste local

Como o projeto é composto por HTML estático, o teste principal é abrir as páginas no navegador e conferir:

- se os arquivos carregam normalmente
- se os favicons aparecem corretamente
- se os links e layouts continuam funcionando
