openssl.md Avançado

OpenSSL

Gerar chaves, criar CSRs, inspecionar certificados, verificar conexões TLS e converter formatos.

7 min
·
16 comandos

Dica rápida

Use | openssl x509 -noout -dates para extrair rapidamente as datas de validade de qualquer certificado.

# Gerar chaves $ openssl genrsa -out privkey.pem 2048 $ openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:P-256 -out ec-key.pem $ openssl rsa -in privkey.pem -pubout -out pubkey.pem # Criar CSR $ openssl req -new -key privkey.pem -out request.csr $ openssl req -new -key privkey.pem -out request.csr -subj "/CN=meudominio.com/O=MinhaOrg/C=BR" # Gerar certificado auto-assinado $ openssl req -x509 -new -nodes -key privkey.pem -sha256 -days 365 -out cert.pem # Inspecionar certificado $ openssl x509 -in cert.pem -text -noout $ openssl x509 -in cert.pem -noout -dates $ openssl x509 -in cert.pem -noout -subject -issuer $ openssl req -in request.csr -text -noout # Verificar conexão TLS $ openssl s_client -connect google.com:443 -servername google.com $ echo | openssl s_client -connect google.com:443 2>/dev/null | openssl x509 -noout -dates # Converter formatos $ openssl x509 -in cert.pem -outform DER -out cert.der $ openssl x509 -in cert.der -inform DER -outform PEM -out cert.pem $ openssl pkcs12 -export -out bundle.pfx -inkey privkey.pem -in cert.pem # Hash & Encode $ openssl dgst -sha256 arquivo.txt $ echo -n "texto" | openssl base64 $ echo "c2V1IHRleHRv" | openssl base64 -d

helm.md Intermediário

Helm

O gerenciador de pacotes do Kubernetes. Repositórios, installs, upgrades, rollback e debug de charts.

7 min
·
16 comandos

Dica rápida

Use helm template antes de instalar para validar os manifestos sem aplicar nada no cluster.

# Repositórios $ helm repo add bitnami https://charts.bitnami.com/bitnami $ helm repo update $ helm repo list # Buscar & Inspecionar $ helm search repo nginx $ helm show values bitnami/nginx $ helm show readme bitnami/nginx # Instalar & Gerenciar $ helm install my-app bitnami/nginx -n production -f values.yaml $ helm upgrade my-app bitnami/nginx -n production -f values.yaml $ helm uninstall my-app -n production $ helm list -A $ helm status my-app -n production # Rollback & Histórico $ helm history my-app -n production $ helm rollback my-app 1 -n production # Debug & Template $ helm lint ./my-chart $ helm template my-app ./my-chart -f values.yaml $ helm diff upgrade my-app ./my-chart -n production # Criar & Empacotar Chart $ helm create my-chart $ helm package ./my-chart $ helm pull bitnami/nginx --untar
