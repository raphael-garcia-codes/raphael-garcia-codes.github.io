Comandos Git
  • git clone <url>Clonar repositório
  • git initInicializar repositório
  • git add <arq|.>Adicionar ao staging
  • git commit -m "msg"Criar commit
  • git branch [nome]Listar / criar branch
  • git checkout <branch>Mudar de branch
  • git merge <branch>Mesclar branch
  • git rebase <branch>Rebase sobre branch
  • git push <rem> <br>Enviar para remoto
  • git pull <rem> <br>Receber do remoto
  • git statusEstado atual
  • git logHistórico de commits
  • git diffDiferenças
  • echo "txt" > arqCriar / editar arquivo
  • cat <arq>Ver conteúdo
  • lsListar arquivos
  • clearLimpar terminal
